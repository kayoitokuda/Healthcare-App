# v0.4.5 Onboarding and UX Pass

## Branch and scope

- Branch: `v0.4.5-onboarding-tutorial`
- Base: `v0.4.4-denial-next-steps`
- This work stays on a development branch. It does not change `main`, merge into production, or alter the v0.4.4 snapshot.
- No database migration, authentication change, offline patient-data storage, or new analytics event is introduced.

## Changes

### Guided onboarding

- Replaced the text-only walkthrough with a guided spotlight tour anchored to real app landmarks.
- With an active referral, the tour highlights Overview, My referrals, the referral card, referral details, the combined timeline, call-script preparation, notes and coverage questions, and Next steps.
- Without an active referral, the tour explains the Overview summary and next-step panel, shows where referrals live, highlights Add a referral, and introduces Next steps without creating sample patient data.
- Each dialogue explains what the highlighted section or tool does and what the patient can do there. The tour scrolls landmarks into view and follows responsive desktop/mobile navigation.
- The tour can be replayed from Help, supports back/next/exit controls and keyboard arrow navigation, and is localized in English, Japanese, Chinese, Spanish, and Vietnamese.
- The walkthrough does not create, edit, or save referral information.

### Referral-specific help

- The referral detail Help view uses the recorded referral milestones and events to select a focused prompt.
- It shows the next-step suggestion, the office or plan to contact, a question to consider, and the latest patient-entered update.
- Prompts are explicitly framed as items to confirm. They do not verify status, provide medical advice, or determine coverage.
- “Record an update” opens the existing update flow.

### Landing page and mobile polish

- Replaced the static sample tracker with an interactive, clearly labeled example referral.
- Added a focused “what you can track” section, expandable FAQs, and a fuller footer with real in-page navigation and account actions.
- Refined the landing-page hierarchy, color use, card surfaces, and restrained motion while keeping the existing logo and type families.
- Removed the inherited fixed hero height that clipped the account buttons. Added a stacked layout at narrower widths and mobile-safe action layouts.
- Corrected the dashboard wordmark rule at very small widths.
